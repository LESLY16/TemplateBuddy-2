## ✨ What is TemplateBuddy?

TemplateBuddy (branded **Web Master Hub & Studio** in the app) is a lightweight, browser-based template gallery built with vanilla HTML, CSS, and JavaScript. It brings a collection of themed landing-page concepts together in one place, so you can preview a design and take its HTML with you—without installing a framework or build tool.

## 🚀 Features

- **12 standalone template concepts** with distinct themes and page sections.
- **Interactive gallery** with category badges and at-a-glance component highlights.
- **Fullscreen previews** to inspect a design before exporting it.
- **One-click HTML downloads**—each template is exported as a self-contained `.html` file with its styles and markup included.
- **Responsive components** such as carousels, feature cards, amenity grids, pricing tables, and contact or booking forms.
- **No framework or build step** required to run the gallery.

> Previews in the gallery are watermarked. Downloaded template files are exported without the preview watermark.

## 📦 Getting started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/LESLY16/TemplateBuddy-2.git
   cd TemplateBuddy-2
   ```

2. Open `index.html` in a modern browser.

That’s it—there are no dependencies to install and no build command to run. For a more consistent local setup, serve the repository with any static-file server.

## 🖱️ Using the studio

1. Browse the template cards in the gallery.
2. Select **Preview** to open a fullscreen view.
3. Select **Download** to save that template as an HTML file.
4. Open the downloaded file in a browser or edit it in your preferred code editor.

## 🎛️ Customizing a template

The exported files are designed to be edited directly. Open the downloaded HTML file and adjust its markup and CSS to fit your project. Many templates define colors and other design choices as CSS custom properties in a `:root` block, making it a convenient place to start when changing the theme.
